# 问题记录

记录调试中遇到的坑、排查过程和结论。
（考核要求：体现调参中遇到的问题与解决思路）

---

## 1. 舵机不动，碰一下地线才动（11-18）

**现象**：上电后云台不补偿；摸舵机臂无阻力（说明没通电）；用手碰一下接地排线，舵机会动一下。

**排查**：

- 读 TIM3 寄存器：`CR1 = 0x81`（CEN=1）、`CCR1 = 1900`、`CCR2 = 1100` → PWM 输出正常
- 舵机臂无阻力 → 不是信号问题，是没电
- 碰地线会动 → 地回路时通时断

**结论**：舵机电源的地线接触不良（面包板孔松 / 电源轨中间断开）。

**解决**：适配器负极直接接到舵机棕线，再引一根到板子 GND；三个地汇到一点。

**教训**：面包板不适合走舵机电流；地线断了，信号再好也没用。

## 2. 动一点点就满幅，底座只能转 90°（11-19）

**现象**：底座稍微一动，舵机就以最大幅度纠正；不管动多少，幅度都一样；底座转到 90° 顶死。

**排查**：

- 读变量：`pitch = -66.9°`、`pid_pitch.output = 400`（饱和）、`servo_pitch_us = 1900`
- 目标角写死为 0°，而上电时实际姿态不是 0° → 误差 66.9° → 输出饱和

**结论**：目标角没有校准，PID 一直工作在饱和区。

**解决（待验证）**：上电时静止采样 20 次取平均，作为目标角（上电自校准）。

**教训**：闭环的目标值必须来自“当前实际姿态”，不能凭空写 0。

---

## 3. 动着动着突然不动，按复位才恢复（11-19）

**现象**：运行一段时间后完全停止，按复位键恢复正常。

**排查**：按复位能恢复 → 单片机卡死，不是舵机断电。

**下一步**：复现时**不要复位**，用 Ozone 看 PC 是否停在 `HardFault_Handler`；
怀疑任务栈不足（sensorTask 余量偏小）。

**待办**：`sensorTask` 栈 512 → 768。

---

## 4. MPU6050 装在面包板上而不是云台上（11-19）

**现象**：无论怎么转云台，姿态只随“整块板子”变化，不随舵机转动变化。

**原因**：MPU 固定在桌面/面包板上，舵机转动不会改变它的读数 →
反馈回路断开，PID 一路积分到饱和。

**解决**：把 MPU 用双面胶/扎带固定在**俯仰平台**上（会跟着舵机转的那块）。

**教训**：闭环的传感器必须装在“执行器能影响”的位置，否则闭环不成立。
