## 2026-10-31 ｜ MPU6050 DMP 初始化失败排查

- **现象**：程序在跑、舵机回中，但 `pitch / roll / yaw` 恒为 0，`mpu_init_ret = 10`
- **排查过程**：
  1. 用 J-Link 直接读 RAM，确认 `mpu_ready = 0`、`mpu_init_ret = 10`（`mpu_init()` 失败）
  2. 读 I2C1 寄存器（SR1/SR2），总线空闲、无错误标志
  3. 用调试器手动位翻转 I2C，地址 0x68 收到 ACK，确认硬件连通
  4. 读 WHO_AM_I(0x75) = **0x74**（正品 MPU6050 应为 0x68），0x06~0x0B 为乱值
- **AI 建议**：判断为兼容芯片，驱动在 `mpu_init()` 的产品版本自检处 `return -1`
- **我的验证**：在 `inv_mpu.c` 中把该分支改为按普通灵敏度继续后重新编译烧录
  → `mpu_ready = 1`，三轴角度正常输出（J-Link 连读两次，数值在变化）
- **结论**：采纳。兼容芯片的数据寄存器与量程（16384 LSB/g）均兼容，DMP 可正常工作

> 教训：不能只看"代码是否跑起来"，要回到寄存器、回到实测数据。
