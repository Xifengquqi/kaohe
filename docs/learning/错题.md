## 错题 1 · 状态机：`AA AA 55` 怎么处理

**题目**：串口收到 `AA AA 55 ...`，解析器会怎样？会不会错乱？

**正确答案**：

- 第 1 个 `AA`：HEAD1 → HEAD2
- 第 2 个 `AA`：在 HEAD2 里收到 `AA`，代码让它**留在 HEAD2** 继续等 `55`
- `55`：进入 LEN，开始正常解析

**所以不会错乱**，只是多等一个字节。关键代码：

```c
case FP_HEAD2:
    if (byte == FRAME_HEAD2)      p->state = FP_LEN;
    else if (byte == FRAME_HEAD1) p->state = FP_HEAD2;   // 关键：连续 AA 不错乱
    else                          p->state = FP_HEAD1;
```

## 错题 2 · `USART1_CR1 = 0x200C` 是哪几位

**题目**：这个值说明串口处于什么状态？

**正确答案**：拆成二进制 `0010 0000 0000 1100`

| 位 | 名称 | 值 | 含义 |
|---|---|---|---|
| bit13 | UE | 1 | 串口总使能 |
| bit3 | TE | 1 | 发送使能 |
| bit2 | RE | 1 | 接收使能 |

再配合 `BRR = 625`（72MHz ÷ 115200），就可以完整说明“115200、8N1、收发都开”。

## 错题 3 · 取舍题要按三行答

**题目**：帧头为什么用 `AA 55` 两个字节？

**正确格式**：

```
选项 A：单字节 0xAA —— 代价：数据里出现 0xAA 就误判，需要转义
选项 B：AA 55 + CRC16 —— 代价：每帧多 1 字节
选择 B：多 1 字节，换掉一整类错误，100Hz 下只多 100 B/s，可以接受
```

**要点**：先列选项，再写各自代价，最后说“为什么选这个”。

## 错题 4 · 状态量 vs 事件

**题目**：姿态数据为什么用共享变量，不用队列？

**正确答案**：

- **状态量**：只关心当前值（现在是 23.5°），旧的没意义 → 共享变量，覆盖写
- **事件**：每条都不能丢（“把目标角设成 30°”）→ 必须用队列
- 用队列传姿态反而有害：消费慢了会积压旧角度，PID 拿过期数据算
